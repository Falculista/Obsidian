# $$\text{Introdução}$$
Todos os seres vivos possuem as chamadas moléculas orgânicas, como glicídios, lipídios, proteínas, etc., que estão dentro das células. Algumas dessas moléculas são os ácidos nucleicos, que pode se manifestar tanto como ácido desoxirribonucleico (DNA) ou como ácido ribonucleico (RNA).

O ácido nucleico possui como função o armazenamento do código genético do indivíduo (isto é, as informações de como seu sistema funciona) por meio de uma sequência das chamadas bases nitrogenadas: adenina (A), timina (T), citosina (C) e guanina (G).
# $$\text{O DNA}$$
O ácido desoxirribonucleico (DNA) é uma das moléculas mais importantes para a vida, pois, como vimos, ela é responsável por armazenar todas as informações acerca do nosso funcionamento como seres vivos. Ao conjunto de moléculas de DNA presentes no organismos nós damos o nome de genoma, o qual reside todo o nosso código genético.
