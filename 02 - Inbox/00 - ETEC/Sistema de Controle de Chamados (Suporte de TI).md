# $$\Large\text{1. Introdução}$$
<p style="text-align: justify">Esse projeto é um sistema de chamados relacionado a suporte técnico. Nesse sistema, será possível criar, remover, atualizar e consultar chamados, de acordo com o padrão <b>CRUD</b>.
<br><br>
Esse programa visa prover um sistema onde o usuário pode criar tickets requisitando assistência de um profissional para solver problemas técnicos atrelados a dispositivos eletrônicos.
</p>

# $$\Large\text{2. Justificativa}$$
<p style="text-align: justify">
Com a alta demanda por dispositivos eletrônicos, sejam esses celulares, computadores ou televisões, diversos usuários acabam necessitando de assistência técnica para resolver problemas ligados a esses aparelhos. Nesse contexto, faz-se necessário a criação de um sistema prático e fácil que possibilite que o consumidor requisite auxílio com profissionais para solucionar tais problemas.
</p>

# $$\Large\text{3. Objetivo Geral}$$
<p style="text-align: justify">
O objetivo desse sistema é prover meios para criar, remover, modificar e consultar tickets relacionados a assistência técnica, de acordo com o padrão CRUD.
<br><br>
Um usuário deve ser capaz de criar tickets, provendo uma descrição do problema que está enfrentando, modificar detalhes de seu ticket e acompanhar o progresso (se o ticket já foi respondido). Um usuário, entretanto, não deve ser capaz de consultar tickets de outros usuários.
<br><br>
Um administrador deve ser capaz de consultar ticket de todos os usuários, responder aos tickets e remover tickets. 
</p>

# $$\Large\text{4. Objetivo Específico}$$
<p>Para a criação desse sistema, serão utilizadas as seguintes tecnologias (tech stack):</p>

- HTML: para a criação do corpo da página web
- CSS: para a estilização da interface de usuário
- PHP: linguagem de programação para a realização da lógica (e.g. envio dos tickets para o banco de dados, logar usuários, salvar sessões).
- MySQL: Banco de dados de padrão SQL utilizado para o registro dos dados do sistema.
