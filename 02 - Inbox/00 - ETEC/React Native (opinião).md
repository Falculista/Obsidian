# $$\Large\text{React Native}$$
React Native é uma tecnologia usada para desenvolver interfaces de usuário (UI) para dispositivos móveis, como celulares Android e iOS, utilizando JavaScript e React. Seu funcionamento se dá pelo que é chamado de "componentização", veja: uma interface é criada pelo front-end, com ele podendo ser feito tudo no mesmo lugar, possivelmente deixando tudo desorganizado em uma tela com botões, cabeçalho, matérias, textos, etc. Você até pode criar `div`'s, mas você não pode "reutilizar" o código dentro delas, como um molde para outras `div`'s semelhantes. A ideia do React é justamente contrapor esse padrão e possibilitar com que você crie componentes que podem ser reutilizados depois.
