# $$\text{Semântica}$$
A semântica é a área da gramática que estuda o significado das palavras. Ela está dividida em:

1. Sinonímia: relativo aos sinônimos (palavras diferentes, mesmo significado) -> ex: certo/correto.
2. Antonímia: relativo aos antônimos (o contrário de) -> certo/errado.
3. Homonímia: grafia/pronuncia idêntica; significado diferente → seção/sessão/cessão
4. Paronímia: grafia/pronuncia semelhante; significado diferente → ex: emergir e imergir
5. Polissemia: mesma palavra; diferentes significados (define-se pelo contexto) → ex: manga (fruta ou parte da camisa)
